### Структура проекта

| Файл / папка | Назначение |
|---|---|
| `main.py` | Точка входа: создаёт `LabRunner` и запускает нужную лабораторную |
| `lab_runner.py` | Класс `LabRunner` с методами `start_1_lab()` и `start_2_lab()`, которые создают `QApplication`, показывают окно и запускают цикл событий |
| `lab1/` | Лабораторная работа № 1 |
| `lab2/` | Лабораторная работа № 2 |
| `.gitignore` | Исключает из репозитория виртуальное окружение, кэш Python и служебные файлы macOS/IDE |

### Запуск

Все команды выполняются из папки `gui`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install PyQt5
python main.py
```

Какая лабораторная откроется, определяет последняя строка в `main.py`:

- `labRunner.start_1_lab()` — лабораторная № 1;
- `labRunner.start_2_lab()` — лабораторная № 2.
