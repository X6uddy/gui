Лабораторные работы по разработке графических интерфейсов на Python и PyQt5.

---

### Структура проекта

| Файл / папка | Назначение |
|---|---|
| `main.py` | Точка входа: принимает номер лабораторной (`python main.py 3`) и запускает её через `LabRunner` |
| `lab_runner.py` | Класс `LabRunner` с методами `start_1_lab()` … `start_4_lab()`. Лабораторные 1–3 запускаются общим методом `start_widget_lab()` (приложение → окно → цикл событий), 4-я создаёт QML-движок |
| `qt_setup.py` | Один раз задаёт Qt пути к плагинам и QML-модулям (лечит ошибки `Driver not found` и `platform plugin`). Вызывается в `LabRunner` до создания `QApplication` |
| `req.txt` | Зависимости (PyQt5) |
| `lab1/` | Лабораторная работа № 1 |
| `lab2/` | Лабораторная работа № 2 |
| `lab3/` | Лабораторная работа № 3 |
| `lab4/` | Лабораторная работа № 4 |
| `.gitignore` | Исключает из репозитория виртуальное окружение, кэш Python и служебные файлы macOS/IDE |

### Лабораторная работа № 1

Окно с надписью и кнопкой: по нажатию надпись заменяется картинкой.

В папке `lab1` лежат:

1. `main_molule.py` — класс `ImageApp`, реализующий логику работы.
2. `nature.jpeg` — картинка, которая показывается по нажатию на кнопку.
3. `README.md` — подробное описание.

### Лабораторная работа № 2

Конвертер валют (USD, RUB, EUR): при изменении одного поля два других пересчитываются автоматически.

В папке `lab2` лежат:

1. `currency_converter.py` — класс `CurrencyConverter`, реализующий логику работы.
2. `README.md` — подробное описание.

---

### Лабораторная работа № 3

Просмотр SQLite-базы данных: подключение к файлу `.db`, пять вкладок с таблицами, кнопки с SQL-запросами и выбор таблицы из списка.

В папке `lab3` лежат:

1. `db_window.py` — класс `DbWindow`, окно приложения.
2. `db_helper.py` — класс `Dbhelper`, создающий тестовую базу.
3. `test_db_lab3.db` — тестовая база (пересоздаётся при каждом запуске лабораторной).
4. `resources/` — задание, `screens/` — скриншоты.
5. `README.md` — подробное описание.

### Лабораторная работа № 4

Мини-редактор рисования на QML (цвет, толщина кисти) с автосохранением холста из Python каждые 5 секунд.

В папке `lab4` лежат:

1. `interface.py` — класс `Interface`: таймер автосохранения и вызов сохранения холста.
2. `resources/template/` — QML-интерфейс (`mainWindow.qml`, `Square.qml`, `Circle.qml`) и исходный шаблон `main.py` из задания.
3. `saved_canvas.png` — результат автосохранения.
4. `README.md` — подробное описание.

### Запуск

Все команды выполняются из папки `gui`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install PyQt5
python main.py 1    # номер лабораторной: 1, 2, 3 или 4 (по умолчанию 4)
```
